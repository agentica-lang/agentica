# Repository map, file by file

One line per file of `src/`, `vm/`, `tests/`, `stdlib/` and `docs/`. The short tree is in `AGENTS.md`; read this to find which file owns something.

```text
src/
  source.rkt      # source, source-position, source-span (span end is exclusive)
  diagnostic.rkt  # diagnostic struct and format-diagnostic
  token.rkt       # token struct
  lexer.rkt       # lex: source -> (listof token) | diagnostic
  ast.rkt         # syntax tree nodes (including enums and case patterns); every node carries a span
  parser.rkt      # parse: (listof token) -> program | diagnostic
  builtins.rkt    # shared signatures, type-rule tags, dispatch keys, effects, descriptions
  checker.rkt     # check: program -> program | diagnostic
  modules.rkt     # import linking: std/, pkg/ and relative files, aliases, exports, cycles; runs before check
  stdlib.rkt      # std/ Agentica sources embedded at compile time
  builtin-types.rkt # opaque handle types, builtin record layouts (Header, HttpResponse, FileInfo, ...) and builtin enums (Await)
  version.rkt     # the version string
  lower.rkt       # lower: checked program + #:types table -> IR | diagnostic (LOWER-); format-ir for --dump-ir
  bytecode.rkt    # ir->bytecode and write-bytecode (BYTECODE-LIMIT, BYTECODE-INTERNAL): the .agcb format of docs/vm/03-ir-and-bytecode.md 4.6; the C loader is the only reader
  bdd-driver.rkt  # agentica test: compiles the step program and the embedded std/test/runner, runs the runner VM, infrastructure report
  vm-launch.rkt   # find-vm, stop-vm, call-noting-break and running-executable, shared by main.rkt and bdd-driver.rkt
  main.rkt        # thin CLI driver: lex, parse, link, check, lower, then run bytecode from a temp file on dist/agentica-vm (`check` only, --dump the tree, --dump-ir, `compile -o`; `test` parses its options and calls bdd-driver.rkt); exit 1 on a diagnostic, 2 on usage, a missing file or a missing VM
compiler/         # the front end in Agentica (35.4, one stage per PR); lexer so far
  source.agc token.agc diagnostic.agc  # Position and Span, Token and its Value, Diagnostic and Outcome[T]
  lexer.agc       # lex: String -> Outcome[List[Token]]; port of src/lexer.rkt
  unicode.agc unicode_table.agc  # graphic? and the char write form for LEX-UNEXPECTED-CHAR; the table is generated by tools/gen-lexer-unicode.rkt
  lex.agc lex_text.agc  # entry: prints the text form of the tokens of each file argument
vm/               # the C11 bytecode VM (dist/agentica-vm); layers in references/vm.md
  value.h         # values and the agc_ value API, shared by all layers (references/vm-core.md)
  port.h          # what services call into the core: park, wake, jobs, handles (references/vm-core.md)
  core.h          # the core types and entry points (references/vm-core.md)
  services.h      # the service exports (references/vm-core.md)
  list_impl.h     # private list layout: list.c, interp.c and vm/tests/list_test.c only (references/vm-core.md)
  value.c         # values and memory; the only file that includes gc.h or calls GC_* (references/vm-core.md, references/vm-c.md)
  text.c          # text forms of values and debug text (references/vm-core.md)
  map.c           # persistent HAMT maps (references/vm-core.md)
  list.c          # opaque persistent lists (references/vm-core.md)
  loader.c        # .agcb loader validation (references/vm-core.md)
  interp.c        # the interpreter: one turn of a task, budgets (references/vm-core.md)
  builtins.c      # core builtins (references/vm-core.md)
  builtin_tables.c # the list of every builtin table (references/vm-core.md)
  strings.c       # String builtins (references/vm-core.md)
  numbers.c       # Int and Float builtins, bit builtins, Time (references/vm-core.md)
  random.c        # the xoshiro256** generator (references/vm-core.md)
  json.c          # the JSON parser and builtins (references/vm-core.md)
  json_value.c    # the Json value: nodes, encoder, builders (references/vm-core.md)
  json_typed.c    # typed decode and schema (references/vm-core.md)
  equal.c         # agc_equal, the deep compare Test.eq uses (references/vm-core.md)
  diag.c          # plain, --ai and --json diagnostics; the stack trace of a runtime error (references/vm-core.md)
  unicode_data.c  # generated write-escape ranges (make vm-unicode) (references/vm-core.md)
  trace.c         # trace points and categories (AGC_TRACE) (references/vm-builtins.md)
  trace.h         # the trace categories (references/vm-builtins.md)
  main.c          # CLI, the end of the run and the exit code (references/vm-io.md)
  loop.c          # libuv event loop and resource registry (references/vm-io.md)
  files.c         # File, Dir and Path builtins (Linux) (references/vm-io.md)
  input.c         # the only stdin reader (references/vm-io.md)
  output.c        # stdout and stderr writers (references/vm-io.md)
  duplex.c        # child channel (fd 3) and Process.spawn_channel (references/vm-net.md)
  process.c       # Process builtins and System.env (references/vm-net.md)
  stream.c        # input buffer and write path shared by processes and TCP (references/vm-net.md)
  tcp.c           # TCP and TLS builtins on libuv handles (references/vm-net.md)
  net.h           # tcp.c connection object for other C modules (references/vm-net.md)
  tls.h           # TLS adapter types (references/vm-net.md)
  tls_openssl.c   # the only file that includes OpenSSL (references/vm-net.md)
  http_parse.h    # HTTP head adapter (references/vm-net.md)
  http_pico.c     # the only file that includes picohttpparser (references/vm-net.md)
  http_body.c     # HTTP body decoder (references/vm-net.md)
  http_fields.h   # header lists and byte buffers for HTTP (references/vm-net.md)
  http_fields.c   # their implementation (references/vm-net.md)
  http_client.c   # HttpWire client builtins (references/vm-net.md)
  http_server.c   # HttpWire server builtins (references/vm-net.md)
  task.c          # scheduler, task cancellation, Task builtins (references/vm-tasks.md)
  channel.c       # Channel builtins (references/vm-tasks.md)
  testing.c       # Test builtins for unit tests (references/vm-tasks.md)
  fuzz.c          # agc_fuzz_one (references/vm-build.md)
  fuzz_main.c     # the mutation driver (references/vm-build.md)
  tools/          # check-layers.sh and its self-test, gen-unicode.rkt (references/vm-build.md)
  third_party/bdwgc        # Boehm GC submodule pinned to v8.2.12, built from extra/gc.c with AGENTICA_GC=vendored (the Linux default links the system libgc)
  third_party/yyjson       # yyjson submodule pinned to 0.13.0, only its reader (JSON.parse)
  third_party/libuv        # libuv submodule pinned to v1.53.0, built by the Makefile on Linux
  third_party/picohttpparser # picohttpparser submodule pinned to v1.4 (HTTP heads)
  third_party/openssl      # OpenSSL submodule pinned to openssl-3.5.9; AGENTICA_OPENSSL=vendored builds it static per mode into build/vm/<mode>/openssl (needs Perl); the default links the system OpenSSL 3
  tests/          # C tests, plain asserts (references/vm-tests.md)
    budget_test.c        # budgets and turn costs
    channel_test.c       # Channel builtins called directly
    each_line_test.c     # File.each_line steps that bytecode cannot reach
    float_text_test.c    # Float text forms
    http_parse_test.c    # HTTP head parser
    json_test.c          # JSON parser and builtins
    list_test.c          # opaque lists at the 32-way boundaries
    loader_test.c        # loader rules, one assert per rule
    loop_test.c          # loop and resource registry
    map_test.c           # persistent maps
    output_test.c        # stdout and stderr writers
    process_test.c       # Process builtins
    random_test.c        # the generator
    stack_test.c         # stack traces
    string_test.c        # String builtins
    task_cancel_test.c   # task cancellation
    text_test.c          # text forms
    tls_test.c           # TLS adapter
    trace_test.c         # trace points
tests/            # rackunit files; the lists of references/vm-tests.md say which covers what
  lexer-test.rkt  # the lexer (references/stages.md)
  parser-test.rkt  # the parser (references/stages.md)
  checker-test.rkt  # ranges, JSON contracts and other checker rules (references/stages.md)
  modules-test.rkt  # import linking, visibility, cross-file diagnostics (references/language-notes.md)
  diagnostic-test.rkt  # excerpt and caret format (references/stages.md)
  examples-test.rkt  # examples/*.agc, rejected fragments, CLI exit codes (references/stages.md)
  bytecode-test.rkt  # step merging, opcode list vs vm/value.h, every builtin on the VM (references/vm-lowering.md)
  frontend-lexer-common.rkt  # the lexer text form and goldens (references/frontend.md)
  frontend-lexer-test.rkt  # the Racket and Agentica lexers against the goldens (references/frontend.md)
  process-test.rkt  # Process builtins on the VM, every way a run ends (references/vm-net.md)
  filesystem-test.rkt  # File and Path programs on the VM (references/vm-io.md)
  cli-in-process.rkt  # helper: runs src/main.rkt in process for CLI tests
  info.rkt        # the Racket package info: lists the tests the runner omits
  vm-diff-common.rkt  # the golden harness: fixtures, sidecars, sweeps (references/vm-build.md)
  vm-diff-{1..8}-test.rkt  # shards of the golden tests (references/vm-build.md)
  vm-latency-test.rkt  # the latency check (references/vm-tasks.md)
  vm-style-test.rkt  # no late type or static prototype in vm/*.c (references/vm-c.md)
  vm-trace-test.rkt  # traced runs keep exit code, stdout and stderr (references/vm-builtins.md)
  vm-tcp-test.rkt  # the VM TCP builtins against Node peers (references/vm-tests.md)
  vm-http-test.rkt  # std/http against independent peers (references/vm-tests.md)
  vm-stop-test.rkt  # the exit path under stop signals (references/vm-tests.md)
  vm-channel-test.rkt  # a socket handed to a worker over a Channel (references/vm-tests.md)
  vm-stdout-test.rkt  # stdout and stderr on the loop (references/vm-tests.md)
  vm-stack-test.rkt  # stack-trace stderr in the three formats (references/vm-tests.md)
  vm-file-lines-test.rkt  # File.each_line on the VM (references/vm-tests.md)
  vm-test-protocol-test.rkt  # a Python peer plays a test runner over the child channel (references/vm-tests.md)
  vm-child-channel-test.rkt  # the child channel on its own, against Python peers (references/vm-tests.md)
  vm-tls-test.rkt  # the VM TLS builtins against independent peers (references/vm-tests.md)
  vm-bits-test.rkt  # spans of the Int and Float bit builtin errors (references/library-notes.md)
  std-binary-test.rkt  # std/binary on the VM (references/library-notes.md)
  site-examples-test.rkt  # every agentica block in site/content runs or checks (references/site.md)
  stdlib-distribution-test.rkt  # the relocated executable still finds std/ (references/ci.md)
  stdlib-docs-test.rkt  # every stdlib module has a module doc and export docs (references/stages.md)
  bdd-test.rkt  # agentica test over the CLI: step programs, isolation (references/bdd.md)
  bdd-integration.rkt  # programs under test, limits, seed, cleanup (references/bdd.md)
  unit-test-test.rkt  # agentica test on *_test.agc files (references/bdd.md)
  std/            # *_test.agc unit tests of the std/ modules
  fixtures/       # golden fixtures and independent Node.js and Python peers
stdlib/                 # std/ modules written in Agentica, embedded by src/stdlib.rkt (an explicit registry keyed "std/<path>.agc")
  queue.agc http.agc binary.agc    # std/queue, std/http, std/binary
  bdd.agc         # std/bdd: the step API of agentica test (BDD.step, BDD.run, the context, the predefined steps)
  bdd/gherkin.agc bdd/match.agc  # internal to agentica test: Gherkin parsing and step matching; see references/bdd.md
  test/report.agc test/runner.agc test/units.agc test/child.agc  # internal to agentica test: the report, the runner, the test-file runner and the child-channel record helpers, shared by unit tests and BDD
examples/               # small programs per feature; examples/README.md lists them
docs/
  grammar.md   # index of the language grammar
  grammar/     # the language definition, one file per section; the source of truth
  future/      # planned syntax, not implemented (one file per section)
  roadmap/     # phases and the active checklist (README.md: current order and rules)
  vm/          # bytecode VM design (phase 7): IR, bytecode, C values, safety rules, PR plan
```
