# Repository map, file by file

One line per file of `src/`, `vm/`, `tests/`, `stdlib/` and `docs/`. The short tree is in `AGENTS.md`; read this to find which file owns something.

```text
src/
  source.rkt      # source, source-position, source-span (span end is exclusive)
  source-file.rkt # read-source-file: strict UTF-8, no size limit, or LEX-INVALID-UTF8 (compiler/source_file.agc does the same)
  diagnostic.rkt  # diagnostic struct and format-diagnostic
  token.rkt       # token struct
  lexer.rkt       # lex: source -> (listof token) | diagnostic
  ast.rkt         # syntax tree nodes (including enums and case patterns); every node carries a span
  parser.rkt      # parse: (listof token) -> program | diagnostic
  constants.rkt   # module constants (§44): the children of a node in source order, the reads of constants, the initialization order and the cycle
  builtins.rkt    # shared signatures, type-rule tags, dispatch keys, effects, descriptions
  checker.rkt     # check: program -> program | diagnostic
  modules.rkt     # import linking: std/, pkg/ and relative files, aliases, exports, cycles; runs before check
  stdlib.rkt      # std/ Agentica sources embedded at compile time, the files listed in stdlib/MODULES
  builtin-types.rkt # opaque handle types, builtin record layouts (Header, HttpResponse, FileInfo, ...), builtin enums (Await) and the `list-type?`, `map-type?`, `set-type?` shape tests shared by the checker and the lowering
  version.rkt     # the version string, read from the VERSION file at compile time
  lower.rkt       # lower: checked program + #:types table -> IR | diagnostic (LOWER-); format-ir for --dump-ir
  bytecode.rkt    # ir->bytecode and write-bytecode (BYTECODE-LIMIT, BYTECODE-INTERNAL): the .agcb format of docs/vm/03-ir-and-bytecode.md 4.6; the C loader is the only reader
  bdd-driver.rkt  # agentica test, the hand-off only: starts dist/agentica-bdd-driver.agcb (compiler/bdd.agc) on the VM with --driver-pid, sends it the embedded std/ sources on stdin, returns its stdout and exit code
  vm-launch.rkt   # find-vm, stop-vm, call-noting-break and running-executable, shared by main.rkt and bdd-driver.rkt
  main.rkt        # thin CLI driver: lex, parse, link, check, lower, then run bytecode from a temp file on dist/agentica-vm (`check` only, --dump the tree, --dump-ir, `compile -o`; `test` hands the words after it to bdd-driver.rkt); exit 1 on a diagnostic, 2 on usage, a missing file or a missing VM
compiler/         # the front end in Agentica (35.4, one stage per PR); lexer, parser, modules, linker, checker, lowering, bytecode writer and BDD driver so far; agentica.toml holds its [style] (lines at most 119 characters)

  lex.agc lex_text.agc  # entry: prints the text form of the tokens of each file argument
  text.agc        # quote, span_text, diagnostic_line: the shared pieces of both text forms
  ast.agc         # the AST structs and enums of src/ast.rkt, with a node id on every node
  parse_base.agc parser.agc  # parse: List[Token] -> Result[Program]; port of src/parser.rkt (parse_base: Env, packed diagnostics, types, patterns; parser: expressions, statements, declarations)
  parse.agc parse_text.agc  # entry: prints the text form of the tree of each file argument
  modules.agc     # load: root path -> every module, read in the order of src/modules.rkt (explicit stack), with CHECK-IMPORT-*, CHECK-DECL-ORDER, CHECK-REDEFINED-NAME
  resolve_import.agc import_path.agc  # std/, pkg/ and relative import resolution, and the import path rules
  resolve.agc rewrite.agc  # resolve: the linked name of a name; rewrite: the declarations of a file with linked names
  linker.agc      # link_file: Linking.Done(Linked) | Failed(Failure); program(): the flat Program for the checker
  declarations.agc suggest.agc link_env.agc link_failure.agc  # declaration helpers and CHECK-DECL-ORDER; did_you_mean; Env and Settings; Site and packed failures with a file
  types.agc builtin_model.agc builtins.agc builtins_data.agc  # the Type enum; builtin data structs and the Rule enum; Catalog (lookups by name); the generated rows (tools/gen-builtins-data.rkt)
  catalog.agc catalog_text.agc  # entry: prints the text form of the catalog, then the answer to each probe argument
  link.agc link_text.agc  # entry: prints the text form of the linked program of each root file argument (flags: --stdlib=, --agentica-path=, --xdg-data-home=, --home=, --ids)
  check_state.agc check_types.agc check_failure.agc  # the checker: Cx and St, type operations and unification, packed Problems with their notes
  check_register.agc check_stmt.agc check_expr.agc  # declarations and main; functions, blocks, statements, case; expressions and operators (CHECK-TOO-DEEP)
  check_call.agc check_method.agc  # calls, enum constructors, struct construction and update; methods and fields (Resolved by node id)
  check_rules.agc check_list.agc check_collections.agc check_args.agc  # the rule of each builtin
  check_const.agc const_walk.agc  # module constants: order, CHECK-CONSTANT-CYCLE, the value and type rules; the children and reads of an initializer
  check_help.agc check_names.agc check_flow.agc check_unused.agc  # help texts, method names, what a body returns, CHECK-UNUSED-VALUE
  check_tables.agc  # generated by tools/gen-check-tables.rkt: method tables and foreign-name helps of src/checker.rkt
  checker.agc     # check(linked, catalog): Checking.Done(Checked: types by node id, resolved) | Failed(Problem)
  check.agc check_text.agc  # entry: prints the text form of checking each root file argument
  ir.agc lower_tables.agc lower_state.agc  # lowering: the IR as data, the tables of src/lower.rkt, Cx and Fx (the function being lowered)
  lower_expr.agc lower_data.agc lower_stmt.agc  # expressions and calls; list, map, enum, struct and update chunks; functions, blocks, statements
  lower_scan.agc lower_const.agc lower_program.agc  # what a function uses; module constants (plan, inlined literals, <start>); struct and enum tables
  lowering.agc    # lower(linked, checked, catalog): Lowered.Done(Ir.Program) | Failed(Problem), function table in the order of src/lower.rkt
  lower.agc lower_text.agc  # entry: prints the text form of lowering each root file argument (flags as check.agc, and --burn=N)
  bytecode_tables.agc bytecode_bytes.agc bytecode_pool.agc  # bytecode writer: format constants and opcode numbers, little-endian integers, UTF-8 and chunk lists, interned tables
  bytecode_spans.agc bytecode_types.agc bytecode_function.agc bytecode_failure.agc  # the span table, the Types and Decodable sections, one function (constants, updates, builtins, labels), BYTECODE- problems
  bytecode_writer.agc  # write(root_dir, program, version): Written.Done(bytes) | Failed(Problem), the sections in the order of src/bytecode.rkt; the version is an input, never a constant
  bdd.agc bdd_driver.agc  # the BDD driver (35.4 step 7): entry (System.args, report, exit code); run(Options) -> Ending, the std/ sources from stdin, the runner and tests compiled into the run directory
  bdd_options.agc bdd_report.agc bdd_files.agc bdd_source_root.agc  # the arguments (driver options, then the user's words); the usage and infrastructure reports; private 0600 writes in pieces; the VM's --source-root of a file
  bdd_discover.agc bdd_compile.agc bdd_rundir.agc bdd_runner.agc  # the walk over the test paths; file -> Compiled.Bytes | Rejected(Problem); the temporary directory, lock and sweep; the runner as a captured child and its report file
  diagnostic_json.agc  # the --json object of a Problem (diagnostic->jsexpr)
  diagnostic_plain.agc diagnostic_ai.agc save_file.agc  # the plain text of a Problem (format-diagnostic of src/diagnostic.rkt) and its --ai text; a file written in pieces (compile -o)
  pipeline.agc  # read_root, check_file, build, compile: link, check, lower and write, shared by the CLI and the BDD driver
  cli.agc  # the command line (35.4 step 8a): run(settings, words, host, hand_off) -> exit status; test calls the BDD driver in process
  cli_options.agc cli_help.agc cli_text.agc cli_reply.agc cli_host.agc  # the options as Racket's command-line reads them; help; the fixed texts; what a command answers; Host and Launch
  cli_spawn.agc cli_main.agc  # the hand-off of an ordinary run (agentica-vm on a private file, stdio through); the runner `make cli` compiles (--version, --stdlib, --vm, --program, then the arguments)
  bytecode.agc    # entry: `ROOT -o OUT` for each file; writes the .agcb and prints `wrote N bytes` or the ERROR line (flags as lower.agc, and `--version=V` for the header)
  front_end.agc front_end_inputs.agc front_end_cli.agc  # the front end of the single binary (35.3, 8b): `--version V [--stdlib DIR] [--self PATH] -- WORDS`, then front_end_cli.agc runs cli.agc over FrontEnd.hand_off; make's stages build it
```
