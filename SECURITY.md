# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release. The current
release version is listed in [`VERSION`](VERSION). Older releases may not
receive security fixes; upgrade before reporting an issue when possible.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub's
**Report a vulnerability** feature on this repository's Security tab. Do not
open a public issue or pull request with an unpatched vulnerability.

If private vulnerability reporting is unavailable, contact the maintainer
through their GitHub profile and ask for a private channel. Include the
affected version, steps to reproduce, and any relevant impact. Please avoid
sending sensitive data that is not needed to reproduce the issue.

The policy covers the Agentica compiler, virtual machine, standard library,
build and release workflows, and published binaries. The maintainer will
review reports and coordinate any fix and disclosure.
