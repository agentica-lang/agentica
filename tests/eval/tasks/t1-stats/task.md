# Task: stats

Write a program that reads integers from standard input, one per line, until the
end of input. There is at least one line. Print three lines:

```text
count: <how many numbers>
sum: <their sum>
max: <the largest>
```

Example input:

```text
3
-1
10
```

Example output:

```text
count: 3
sum: 12
max: 10
```

Save the program as `solution.agc` (Agentica) or `solution.py` (Python), as the
instructions you were given say. It must be a complete program. Test it with
your own input before you finish.
