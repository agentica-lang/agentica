# Task: word count

Write a program that reads lines of words from standard input until the end of input. Words are separated by single spaces. Count how many times each word appears, ignoring upper and lower case (`The` and `the` are the same word).

Print one line per distinct word, `<word> <count>`, with the word in lower case, in the order each word first appeared. There is at least one word.

Example input:

```text
the cat
The dog and the cat
```

Example output:

```text
the 3
cat 2
dog 1
and 1
```

Save the program as `solution.agc` (Agentica) or `solution.py` (Python), as the instructions you were given say. Test it with your own input before you finish.
