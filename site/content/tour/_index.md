A short walk through the language. Each page shows one idea with small
programs you can run. Every example is a complete program: save it as a `.agc`
file and run it with `agentica file.agc`. The box under each program shows
what it prints.

Read the pages in order the first time. The formal rules are in the
[language specification](/reference/).
