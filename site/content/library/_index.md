The builtin modules, grouped by topic. Every function has its signature, a short description and a small example. Functions in the `String`, `List`, `Map`, `Set`, `Range`, `Int`, `Float`, `Result` and `JSON` modules whose first parameter has that type can also be called as methods: `String.upcase(s)` is the same as `s.upcase`.

You can also look up any builtin from the command line with `agentica help NAME`; `agentica help` alone lists the namespaces, and `agentica help --json` prints every builtin as one JSON array.
