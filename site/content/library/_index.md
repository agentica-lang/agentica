The builtin modules, one page each. Every function has its signature, a short
description and a small example. Functions whose first parameter is a
`String`, `List`, `Map`, `Float`, `Result` or `Json` can also be called as
methods: `String.upcase(s)` is the same as `s.upcase`.

You can also look up any builtin from the command line with
`agentica help NAME`.
