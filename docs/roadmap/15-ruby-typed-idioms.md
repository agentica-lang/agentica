## Phase 15: Ruby typed idioms

Specified in [`docs/future/25-ruby-typed-idioms.md` section 25](../future/25-ruby-typed-idioms.md#25-ruby-typed-idioms), Part A. Order step 7.4, after 7i deletes the evaluator (order 7.2): every item changes the front end and `src/lower.rkt` and runs on the C VM only, never on the Racket evaluator. One small PR per item, each with `grammar.md`, the programming skill, the site page, the development skill's notes and tests (parser, lexer and checker tests that assert codes and spans, golden VM fixtures, site examples). The items are independent, except where noted. Library items follow the library rule (after the order table): their code is Agentica in the compiler prelude, and the only builtins are `Float.to_fixed` (public, under its exception 5) and the internal `__fail_arg` (prelude-only, guarded by the loader). Part B (§25.12) and Part C (§25.13) add no items.

- [ ] 15a Default parameter values (§25.1): `CHECK-DEFAULT-ORDER`, `CHECK-DEFAULT-VALUE`, `CHECK-ARITY` with a range; `lower.rkt` fills the missing arguments at the call site. Docs: `grammar.md`, the programming skill, `site/content/tour/functions.md`.
- [ ] 15b Re-exports `export Alias.name` (§25.2), in the linker (`src/modules.rkt`) only. Docs: `grammar.md`, `references/modules.md`, `site/content/tour/modules.md`.
- [ ] 15c Struct update `value.with(field: x)` (§25.3). The ban on `Fn` fields named `with` comes here, in advance, so that 10a stays non-breaking. Breaking change: an `Fn` field named `with` becomes `CHECK-REDEFINED-NAME` (say so in the changelog). Docs: `grammar.md`, the programming skill, `site/content/tour/structs.md`.
- [ ] 15d Value equality for structs, enums, lists, maps and Results (§25.4): the checker rule and the VM's `EQ`/`NE` opcodes with an explicit stack; a bytecode format version bump (an opcode's meaning changes). Docs: `grammar.md`, the programming skill, `site/content/tour/structs.md`, `docs/vm/`, `docs/vm/03-ir-and-bytecode.md` (`EQ` and `NE`).
- [ ] 15e Standalone lambdas `lambda do |x: Int| ... end` (§25.5). Breaking change: `lambda` becomes a reserved word (say so in the changelog). Docs: `grammar.md`, the programming skill, `site/content/tour/blocks.md`, section 11.4.
- [ ] 15f The compiler prelude and the Enumerable methods on `List`, `Range` and `Map` (§25.6), with `select` as an alias of `filter`. The prelude modules are always linked, checked once at build time with the result cached next to the embedded source, and `lower.rkt` emits only the prelude functions the checked program reaches. Runtime errors in prelude code are reported at the user's call or argument (`__fail_arg`, a prelude-only intrinsic), and prelude frames are skipped in stack traces. User calls into the prelude never lower to `tail-call`. Every prelude function is O(n) plus callbacks (prepend and reverse once, or build on `filter`/`map`), with each cost in the `grammar.md` table and a 100,000-element golden with its step count. A bytecode format version bump: `src/bytecode.rkt` writes a prelude flag on each function and the argument spans on prelude calls; `__fail_arg` is a builtin that the loader (`vm/loader.c`) rejects outside prelude functions. Docs: `grammar.md`, `references/builtins.md`, `site/content/library/list.md`, `range.md` and `map.md`, the development skill, `docs/vm/03-ir-and-bytecode.md` and `docs/vm/08-loader-and-cli.md`.
- [ ] 15g `unless ... else ... end` (§25.7). Breaking change: `unless` becomes a reserved word (say so in the changelog). Docs: `grammar.md`, the programming skill, `site/content/tour/control-flow.md`.
- [ ] 15h Statement modifiers `S if c` and `S unless c` (§25.8), with `CHECK-MODIFIER-BINDING`; `break` and `next` are loop control before a newline or a modifier. Gated: an evaluation round with a second model must show that agents use them well before this item ships (section 11's rule). Needs 15g for `unless`.
- [ ] 15i `File.open(path, mode, timeout_ms) do |f| ... end` closes the handle when the block ends (§25.9). Docs: `grammar.md`, `references/files.md`, `site/content/library/files.md`.
- [ ] 15j Heredocs `<<~NAME` (§25.10), lexer only: `LEX-UNTERMINATED-HEREDOC`, `LEX-HEREDOC-INDENT`. Docs: `grammar.md`, the programming skill, `site/content/tour/strings.md`.
- [ ] 15k `format("...", args)` with a literal format checked at compile time (§25.11): `CHECK-FORMAT-LITERAL`, `CHECK-FORMAT-SPEC`, the prelude `format.agc` and the `Float.to_fixed` builtin. Breaking change: a user `def format` becomes `CHECK-REDEFINED-NAME` (say so in the changelog). Needs 15f (the prelude). Docs: `grammar.md`, `references/builtins.md`, `site/content/library/string.md` and `numbers.md`.

**Done when:** each item's site examples run on the VM, and an evaluation round shows the new forms checked and used by agents with the same diagnostic quality as the forms they replace.
